## 交付与回退

先停止系统并备份现有程序目录，再将ZIP内文件覆盖到现有程序根目录，重启并Ctrl+F5刷新。查看新官网选项，用新建任务测试；旧任务里的历史名称不会迁移。发生问题时停止系统并恢复安装前备份的程序文件与配置，保留甲方数据和报告。
